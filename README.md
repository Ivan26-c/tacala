# Tacala - PDF Studio y Escáner HP LaserJet Pro MFP 4103fdw

Editor, organizador y digitalizador profesional de documentos PDF en el navegador con soporte nativo de escaneo en red para la multifuncional **HP LaserJet Pro MFP 4103fdw**.

---

## 🚀 Cómo usar en cualquier PC con Windows (Sin instalar nada)

1. Descarga este repositorio en formato ZIP (botón verde **Code** > **Download ZIP**) y descomprímelo.
2. Entra a la carpeta y dale **doble clic** a:
   👉 **`iniciar_sin_instalar_nada.bat`**
3. Se abrirá automáticamente la aplicación en tu navegador (`http://localhost:3000/`).

> [!NOTE]
> No requiere instalar Node.js ni ningún programa externo. Utiliza el motor nativo de Windows (PowerShell).

---

## ✨ Características principales

- **Escaneo por Red con HP 4103fdw:**
  - Comunicación directa mediante protocolo eSCL / AirScan.
  - Soporte para **Cama plana** y **Alimentador automático (ADF)**.
  - **Escaneo a doble cara automático (Dúplex)** persistente (recuerda si lo dejaste activado o desactivado).
  - Botón **"Escanear más hojas"** para sumar páginas adicionales al mismo documento.
- **Enderezado de Hojas (Deskew):**
  - Corrige inclinaciones en documentos que el alimentador jaló chuecos.
  - Ajuste fino de ángulo (-15° a +15°) con cuadrícula visual de referencia recta.
- **Selección Múltiple (`Ctrl + Click` / `Shift + Click`):**
  - Mover múltiples hojas en grupo arrastrando con el ratón.
  - Rotar y eliminar hojas seleccionadas en bloque.
- **Guardado en tu PC:**
  - Botón **"Guardar en PC"** para elegir directamente en qué carpeta de tu computadora guardar el archivo.
- **Editor y Lienzo:**
  - Dibujo con pluma, resaltador, texto y borrador.
- **Agregar Hojas:**
  - Hojas en blanco (A4 blanca, rayada, cuadrícula, oscura) o desde imágenes (PNG, JPG).
